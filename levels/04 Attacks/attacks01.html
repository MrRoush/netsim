Bob and Alice use a simplified key exchange before sending a message. The exchange is not authenticated, so Alice cannot tell whether the key really came from Bob. This makes the example vulnerable to a man-in-the-middle (MITM) attack.

Eve controls a router between Alice and Bob. She can inspect and change packets that pass through it, including packets that claim to come from Alice or Bob.

Use the packet editor to make Alice accept Eve's key, 31337, while still sending Bob a message he can read with his key, 123456. The key values in this activity are labels; the simulator does not perform real encryption or prove a user's identity.

Hint: Pause the simulation and inspect the example exchange at the top. Follow the packet fields to see which key Alice and Bob use.

Level Objectives

  • Make Alice use Eve's key, 31337.
  • Make sure Bob receives the message using his key, 123456.
