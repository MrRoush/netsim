Each router reduces a packet's time to live (TTL) by one. This limit helps prevent packets from circling forever. When the TTL runs out, a router drops the packet and sends an error message back.

The routers' addresses are hidden. Use the TTL and the error messages to discover them.

Connection to real networks: Traceroute sends probes with different TTL values to learn which routers respond. Real networks may filter or handle these probes differently.

Level Objectives

  • Use TTL error replies to find router addresses.
  • Send a ping to each of the four routers between Alice and Google.
