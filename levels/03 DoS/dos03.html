The router in this activity responds to a simplified broadcast ping. A broadcast is addressed to a whole local network instead of one device. The router copies the request to the other connected devices, and devices that reply can create more traffic.

Google's capacity is higher here, so traffic from one computer is not enough. You control one computer, but can ask other devices to reply to a broadcast. A historical attack called a smurf attack abused this behavior, often with a spoofed source address. Networks are designed to prevent such misuse; this is a simplified, defensive learning example.

Try a packet with dstip set to Broadcast. Observe the replies, then consider how the source-address field changes where those replies go.

Level Objectives

  • Send a ping to Broadcast.
  • Get Barbara to send a packet to Google.
  • Fill Google's capacity meter.
  • Try to do this with one packet in the editor (you may use Repeat).
