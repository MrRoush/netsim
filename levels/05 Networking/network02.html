A hub repeats incoming traffic to its other connections. A switch learns which device is on each connection and can send known traffic only where it needs to go. A router connects different networks; it is not the same as a switch.

This activity uses the packet's source and destination labels to show the idea. Real Ethernet switches learn MAC addresses, which are not modeled here. Send one packet through the hub and notice that both other computers receive it. Then watch the switch learn Erin's location and send Dana's packet only to Erin.

Level Objectives

  • Send a packet from Alice to Bob through the hub; confirm that Charlie also receives a copy.
  • Send a packet from Dana to Erin through the switch.
