A hub copies every incoming packet to its other connections. A switch learns which device is connected to each port and forwards a packet only to the known destination's port. Real Ethernet switches learn MAC addresses (hardware addresses); this simulation instead uses the packet's srcip and dstip labels. A router connects different networks, unlike a hub or switch.

For both packets, enter the sender and recipient in the Network layer: srcip is the sender and dstip is the intended recipient. Leave the Transport and Application fields blank.

  1. Add a packet sent from Alice with Network srcip Alice and dstip Bob. Send it through the hub. Notice that Bob and Charlie both receive a copy.
  2. The simulation first sends Erin's packet to Dana automatically, teaching the switch Erin's port. Add a packet sent from Dana with Network srcip Dana and dstip Erin. Send it and notice that only Erin receives it.

Level Objectives

  • Compare how the hub and switch forward packets.
