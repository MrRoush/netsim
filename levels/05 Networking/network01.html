DNS (Domain Name System) looks up the network address associated with a site name. The packet editor has three parts: the network layer says who sends the packet (srcip) and who should receive it (dstip); the transport section identifies the protocol (proto) and also includes ttl, a limit on how many router hops a packet can take; the application layer describes the request (type) and its data (key). This activity uses a simplified DNS exchange, not a complete DNS service.

  1. Add a packet from Alice. Set Network srcip to Alice and dstip to DNS; Transport proto to DNS; and Application type to query and key to learn.example. Leave ttl blank, then send it.
  2. Pause when the answer reaches Alice and inspect it. Its Application key is Web Server, the name of the server (its address is hidden until DNS reveals it). Add a packet from Alice with Network srcip Alice and dstip Web Server, and Application type web-request. Leave the other fields blank and send it.

Level Objectives

  • Ask DNS for learn.example and use its answer to send a web request to the Web Server.
