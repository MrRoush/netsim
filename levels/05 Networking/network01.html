DNS helps a computer find an address for a site name. People can remember names more easily than numeric addresses. In this activity, Alice asks the DNS server to look up learn.example.

Pause when the answer returns. Its application-layer key shows the server address to use. Then send a web request to that device. This is a small, fixed DNS example, not a complete DNS service.

Level Objectives

  • Ask DNS for learn.example.
  • Use the returned address to send a web request to the Web Server.
