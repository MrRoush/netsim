A firewall checks network traffic against rules. This firewall blocks packets whose source address is Bob and allows other traffic through its server-facing port. Real firewalls can use more detailed rules than this example.

Send Alice's request to the service and observe that it arrives. Then send the same kind of request from Bob. The second packet reaches the firewall but is blocked there because its source matches the rule.

Level Objectives

  • Send a request from Alice to the service.
  • Test Bob's request and confirm that it stops at the firewall.
