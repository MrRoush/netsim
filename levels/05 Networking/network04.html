A firewall checks packets against rules and forwards or blocks them accordingly. This firewall's rule blocks packets whose Network srcip is Bob; other packets are forwarded to the service. Real firewalls can check more information than this simplified example.

For each packet, leave Transport and Application key blank, and set Application type to web-request. Send the first packet from Alice with Network srcip Alice and dstip Service. It passes through the firewall. Then send one from Bob with srcip Bob and dstip Service; it reaches the firewall and is blocked because its source matches the rule.

Level Objectives

  • Compare the firewall's handling of requests from Alice and Bob.
