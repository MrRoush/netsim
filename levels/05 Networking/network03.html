DHCP is commonly used to give devices their network settings when they join a network. The messages in this activity are a simplified discover, offer, request, and acknowledge sequence. The server offers Alice the practice address 192.0.2.10.

First inspect the offer. Then create a request with application type set to request and key set to 192.0.2.10. After the server confirms the address, use it as the source address for a web request.

Level Objectives

  • Receive the server's address offer.
  • Request and receive confirmation of 192.0.2.10.
  • Send a web request using the assigned address.
