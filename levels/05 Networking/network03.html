DHCP (Dynamic Host Configuration Protocol) gives a device network settings, such as its IP address, when it joins a network. The server and Alice demonstrate the four-message sequence: discover asks for settings, offer proposes an address, request asks to use it, and acknowledge confirms it. Here, the offered practice address is 192.0.2.10.

  1. Wait for the automatic discover and offer packets. Pause and inspect the offer to see 192.0.2.10 in its Application key.
  2. Add a packet from Alice. Set Network srcip to Alice and dstip to DHCP Server; Transport proto to DHCP; and Application type to request and key to 192.0.2.10. Leave ttl blank, then send it. Pause to inspect the acknowledge.
  3. After confirmation, add a packet from Alice with Network srcip 192.0.2.10 and dstip Web Server, and Application type web-request. Leave the Transport fields and Application key blank, then send it.

Level Objectives

  • Request and receive confirmation of 192.0.2.10, then use it as the source address for a web request.
