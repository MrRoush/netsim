# netsim
Web-based network simulator for teaching hacking to high schoolers

# try it out
You don't need to download and run the code yourself; you can use our hosted version at [netsim.erinn.io](https://netsim.erinn.io/).

# installation
Netsim is a static site (HTML/JS only): no PHP, database or login is needed. Student progress is stored in each browser's localStorage.
- To run locally: `python3 -m http.server` in this folder, then browse to http://localhost:8000/
- To host it for students, see [HOSTING.md](HOSTING.md)
